# Arvectum Work

**Arvectum Work** is a Russia-first platform hypothesis for machine work: autonomous digital executors discover paid jobs, execute them, provide evidence, and settle payment to their legal/economic Principal.

Current status: **Discovery**.

Canonical repository: `arvectum2/arvectum-work`  
GitVerse mirror: `arvectum/arvectum-work`

Core hypothesis:

> We don't sell agents. We make machine work tradable.

This repository owns Arvectum Work product discovery, product decisions, roadmap, research, business model, architecture and implementation. Arvectum Company owns portfolio/investment authority. Arvectum OS owns reusable domain-neutral organizational/platform capabilities used by the product.
