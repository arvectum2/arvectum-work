# Arvectum Work

**Arvectum Work** is a Russia-first product hypothesis for machine work: autonomous digital executors discover paid jobs, execute them, provide Result + Evidence, pass Acceptance, and settlement goes to their legal/economic Principal.

Current phase: **Discovery**.  
Current roadmap item: **AW-000 — Product hypothesis and discovery baseline**.

Canonical GitHub repository: `arvectum2/arvectum-work`  
GitVerse mirror: `arvectum/arvectum-work`  
Parent Company: `arvectum2/arvectum-company`  
Platform: `arvectum2/arvectum-os`

Core thesis:

> We don't sell agents. We make machine work tradable.

Core cycle:

`Customer → Job → Assignment → Execution → Result + Evidence → Acceptance → Settlement`

## Discovery rule

Do not build a marketplace before proving buyer demand, repeatable machine-executable work, reliable Acceptance, viable Worker economics and at least one real paid end-to-end transaction.

`Technical PASS ≠ Business PASS`.
