## Challenge observations

1. Human freelance marketplaces already expose much of the transactional vocabulary Work may need, but that is not evidence that buyers accept machine executors.
2. Agent platforms make internal build easier, so Work cannot rely on "AI availability" as a moat.
3. Public implementation prices create a useful build-vs-buy anchor, but buyer interviews must test whether those projects are actually perceived as painful or avoidable.
4. Settlement/legal ergonomics from human-contractor platforms cannot be copied by analogy to machine work without transaction-specific review.
